# 🤖 Личный ИИ-помощник в Telegram

Бот, с которым общаешься как с человеком, а он ведёт твои траты, цели и напоминания.

## Что умеет

| Ты пишешь | Бот делает |
|---|---|
| «кофе 250», «вчера такси 600» | записывает трату и сам выбирает категорию |
| 📸 фото чека | распознаёт покупки и записывает их |
| «сколько ушло на кафе в октябре?» | считает по базе |
| «лимит на кафе 5000 в месяц» | предупреждает на 80% и при превышении |
| «хочу накопить 80 000 на ноутбук к марту» | заводит цель, по `/plan` составляет пошаговый план |
| «отложил 5000 на ноутбук» | обновляет прогресс цели |
| «напомни завтра в 9 позвонить маме» | напоминает в нужное время (умеет каждый день/неделю/месяц) |
| «запомни, что зарплата 10 числа» | помнит и учитывает в советах |

И пишет первым:
- ⏰ напоминания;
- 📅 **1-го числа**: умный отчёт за прошлый месяц (куда ушли деньги, сравнение, советы под твои цели);
- 🎯 **в воскресенье вечером**: короткий чекин по целям.

Команды: `/report`, `/goals`, `/plan`, `/month`, `/reminders`, `/reset`, `/help`.

## Какие модели и сколько это стоит

- Обычное общение идёт через **Claude Haiku 5.5**, самую дешёвую модель ($0.10 за 1 млн входных токенов). Одно сообщение стоит примерно десятую долю цента.
- Отчёты и планы по целям делает **Claude Opus 5.5**, умную модель. Один отчёт или план стоит примерно 5–15 центов.

При обычном личном использовании выходит около **$1–2 в месяц**. Модели можно поменять в `.env` (`CHAT_MODEL`, `SMART_MODEL`). Например, `claude-sonnet-5-5` для чата будет умнее Haiku, но дороже.

## Запуск за 10 минут

### 1. Создай бота
1. В Telegram открой [@BotFather] и отправь `/newbot`.
2. Придумай имя и юзернейм.
3. Скопируй токен вида `123456789:ABC...`.

### 2. Получи ключ Claude API
1. Зайди на [console.anthropic.com](https://console.anthropic.com), зарегистрируйся и пополни баланс (хватит $5).
2. В разделе **API Keys** создай ключ `sk-ant-...`.

### 3. Запусти
Нужен Python 3.11 или новее.

```bash
cd tg-assistant
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
```

Открой `.env`, впиши `TELEGRAM_TOKEN` и `ANTHROPIC_API_KEY`, затем запусти:

```bash
python bot.py
```

### 4. Пусти себя
1. Напиши боту что угодно. Он ответит: «Твой Telegram ID: 123456».
2. Впиши этот ID в `.env`: `ALLOWED_USERS=123456`.
3. Перезапусти бота (Ctrl+C, потом снова `python bot.py`).

Так бот отвечает только тебе, и чужие люди не тратят твои деньги на API.

## Чтобы бот работал 24/7

Пока окно с `python bot.py` открыто, бот работает. Если компьютер выключить, бот замолчит, и напоминания придут только после перезапуска.

Чтобы бот был всегда онлайн, запусти его на маленьком сервере. Подойдёт любой VPS за 150–300 ₽ в месяц, Raspberry Pi или бесплатный тариф облака. Шаги те же, что выше. Чтобы бот не падал после закрытия терминала, запускай его через `screen`, `tmux` или systemd.

## Где хранятся данные

Всё лежит в одном файле `assistant.db` (SQLite) рядом с ботом: траты, цели, напоминания, память и история разговора. Чтобы перенести данные, скопируй этот файл. Чтобы стереть всё, удали его.

## Устройство (для любопытных)

- `bot.py`: Telegram-часть (aiogram), команды и фоновые задачи (напоминания, отчёт, чекин).
- `ai.py`: общение с Claude: чат с инструментами, отчёт, план, распознавание чеков.
- `tools.py`: «руки» ИИ, то есть инструменты, которыми он записывает траты, цели и напоминания.
- `db.py`: база данных.

Когда история разговора становится длинной (`HISTORY_LIMIT`), бот сжимает её в краткое резюме и продолжает. Траты и цели при этом не теряются, они лежат в базе отдельно.
